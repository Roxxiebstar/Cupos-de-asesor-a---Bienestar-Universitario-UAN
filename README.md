# Sistema de Reservas — Bienestar UAN

Sistema web desarrollado para facilitar la reserva de citas de Orientación Psicosocial y Asesoría de Lectura y Redacción Académica para estudiantes de la Universidad Antonio Nariño.

## Descripción

El sistema permite a los estudiantes consultar los horarios disponibles y realizar, consultar o cancelar sus reservas de manera sencilla, evitando el proceso manual de asignación de horarios.

## Funcionalidades

- Selección del tipo de asesoría.
- Identificación del estudiante.
- Consulta de horarios disponibles.
- Creación de reservas.
- Prevención de reservas solapadas.
- Una reserva activa por estudiante.
- Consulta de "Mis reservas".
- Cancelación de reservas.
